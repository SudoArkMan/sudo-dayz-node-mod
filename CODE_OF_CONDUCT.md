# Code of conduct

This is a small project in the DayZ modding community. The rules are short
because they only need to cover what actually goes wrong.

## What is expected

Take part on the assumption that the person you are talking to is trying to
build something. Disagree about the code as much as you like. Be specific about
what is wrong and why, because that is the part anybody can act on.

Reviews criticise the work, not the author. "This rewrites the file the user
opened" is a review. "You clearly did not read anything" is not.

If somebody is new to Qt, to C++, or to Enforce Script, that is not a defect in
them. Everybody arrives not knowing this codebase.

## What is not acceptable

- Harassment, in the issue tracker, in pull requests, or anywhere the project
  is being discussed. This includes sustained personal attacks, sexual
  attention that is not wanted, and following somebody across threads to keep
  at them.
- Insults or dismissals aimed at a person rather than their work.
- Slurs and demeaning remarks about who somebody is: their nationality, race,
  religion, disability, sex, gender identity, sexual orientation, age or
  appearance.
- Publishing somebody's private information without their permission.
- Deliberately wasting maintainer time: spam, pull requests that fake a passing
  test suite, or reports written to provoke rather than to be fixed.

## Where this applies

Anywhere the project lives. Issues, pull requests, discussions, commit
messages, and anywhere somebody is representing this project in public.

## Reporting

If something here is being broken, tell the maintainer privately rather than
arguing it out in a thread. Email Dillan Stephenson at sudoarkman@gmail.com.

Reports are read privately, and who reported what is not shared. You will not
be told you should have handled it yourself.

## What happens then

The maintainer decides. In rough order: a private word, a public correction, a
comment or a pull request removed, a temporary block, a permanent block.
Severity and whether it is a pattern both count. A first mistake handled well
is not the same as the same thing for the third time.

There is one maintainer, so there is no appeals board. If you think a decision
was wrong, say so in the same private channel, once.
